# The AI Guide Academy: mobile app

**Download:** [Ai-guide.apk](https://ai-guide-app-liart.vercel.app/Ai-guide.apk) (Android 7.0 or newer) · **Website:** [client-m7q4.vercel.app](https://client-m7q4.vercel.app) · **API:** [ai-guide-uo4m.onrender.com](https://ai-guide-uo4m.onrender.com/api/health)

A Flutter app (Android and iOS) for the academy. It uses the same server, the same accounts and the exact same progress format as the website, so a learner can switch between phone and browser freely.

## What is in it

| Area | How it works |
| --- | --- |
| Lessons, cheat sheet, reference pages | Rendered in a WebView with the website's own HTML, KaTeX math, SVG figures, highlighted code and interactive widgets. They follow the app theme and fonts. Links between lessons open native screens. Works offline. |
| Quizzes and final exams | Native. Math in questions is typeset natively from the LaTeX. Grading, pass marks, exam draws and certificate IDs are line-for-line ports of the website (`test/logic_test.dart` checks them against values produced by the website code). |
| Python exercises | Pyodide runs in a Web Worker inside a hidden WebView, like on the website. It needs internet the first time (about 10 MB), then it is cached. |
| Progress and sync | Saved on the phone. When signed in, every change is pushed to the server about a second later and merged with the website's progress on sign-in, using the same rules as the website. |
| Accounts | Sign in, register, change name and password, request account deletion, sign out. |
| Admins | Admin accounts only see the admin area: learners with stats and per-course progress, deletion requests (keep or delete), and settings. |
| Appearance | Light, dark or system; the website's 20 colour themes; 13 interface, 8 lesson and 6 code fonts; reading size; animations on or off. |

## Run it

Requires Flutter 3.47 or newer (Dart 3.13), and Node to run the content sync script.

```bash
# 1. Copy the latest content from the website (after `npm run content` in client/)
node tool/sync_content.mjs

# 2. Start the server (see ../server), then run the app
flutter pub get
flutter run
```

By default the app talks to the deployed API at `https://ai-guide-uo4m.onrender.com`. Point it elsewhere at build time:

```bash
flutter run --dart-define=API_URL=http://10.0.2.2:4000          # a local server, from the Android emulator
flutter build apk --release --dart-define=SITE_URL=https://client-m7q4.vercel.app   # where the website is hosted
```

`SITE_URL` (default `https://client-m7q4.vercel.app`) is used for the policy pages and "Open the website".

The address can also be changed inside the app under **Me → Server**.

## Before publishing

- The default API is already `https`, so you can remove `android:usesCleartextTraffic="true"` from `android/app/src/main/AndroidManifest.xml` and the `NSAppTransportSecurity` block from `ios/Runner/Info.plist`. They exist only so a plain-http development server works.
- Change `applicationId` in `android/app/build.gradle.kts` and the iOS bundle identifier if you want a different id than `com.aiguideacademy.ai_guide_academy`, and set up signing.
- Android 8+ uses the adaptive launcher icon in `android/app/src/main/res/mipmap-anydpi-v26`; older Android versions and iOS still use the default Flutter icons, so replace those before release.

## Layout

```
lib/
  main.dart, app.dart        startup, providers, root routing (splash / welcome / learner / admin)
  core/api.dart              HTTP client and server address
  data/                      content models and the bundled-content loader
  logic/                     grading and progress rules (ports of client/src/lib)
  state/                     progress, auth + sync, appearance
  theme/                     the 20 palettes (OKLCH, same as the website) and ThemeData
  widgets/                   UI kit, lesson WebView, Python runner, question card, HTML+math renderer
  screens/                   one file per screen; admin/ holds the admin area
assets/content/              copied from client/src/generated by tool/sync_content.mjs
assets/web/                  lesson.css (KaTeX with embedded fonts + lesson styles), widgets.js
test/logic_test.dart         parity tests against the website's logic
```
