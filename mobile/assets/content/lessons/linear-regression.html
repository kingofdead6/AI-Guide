Model and loss

y^=Xw,L(w)=∥y−Xw∥22\hat{\mathbf y}=\mathbf X\mathbf w,\qquad \mathcal L(\mathbf w)=\|\mathbf y-\mathbf X\mathbf w\|_2^2y^​=Xw,L(w)=∥y−Xw∥22​

(Absorb the bias by adding a column of ones to X\mathbf XX.)

Derivation: the normal equations

∇wL=−2X⊤(y−Xw)=0  ⇒  X⊤Xw=X⊤y  ⇒  w^=(X⊤X)−1X⊤y\nabla_{\mathbf w}\mathcal L=-2\mathbf X^\top(\mathbf y-\mathbf X\mathbf w)=0\;\Rightarrow\;\mathbf X^\top\mathbf X\mathbf w=\mathbf X^\top\mathbf y\;\Rightarrow\;\boxed{\hat{\mathbf w}=(\mathbf X^\top\mathbf X)^{-1}\mathbf X^\top\mathbf y}∇w​L=−2X⊤(y−Xw)=0⇒X⊤Xw=X⊤y⇒w^=(X⊤X)−1X⊤y​

Geometry: Xw^\mathbf X\hat{\mathbf w}Xw^ is the orthogonal projection of y\mathbf yy onto the column space of X\mathbf XX; the residual is perpendicular to every feature column (X⊤r=0\mathbf X^\top\mathbf r=0X⊤r=0). Probability: with y=w⊤x+ε, ε∼N(0,σ2)y=\mathbf w^\top\mathbf x+\varepsilon,\ \varepsilon\sim\mathcal N(0,\sigma^2)y=w⊤x+ε, ε∼N(0,σ2), this is the MLE (Statistics: MLE, MAP & Where Loss Functions Come From).

Regularization

Ridge: min⁡w∥y−Xw∥2+λ∥w∥22  ⇒  w^=(X⊤X+λI)−1X⊤y\text{Ridge: }\min_{\mathbf w}\|\mathbf y-\mathbf X\mathbf w\|^2+\lambda\|\mathbf w\|_2^2\;\Rightarrow\;\hat{\mathbf w}=(\mathbf X^\top\mathbf X+\lambda\mathbf I)^{-1}\mathbf X^\top\mathbf yRidge: wmin​∥y−Xw∥2+λ∥w∥22​⇒w^=(X⊤X+λI)−1X⊤y

Adding λI\lambda\mathbf IλI makes the matrix always invertible and shrinks weights, which reduces variance. Lasso uses λ∥w∥1\lambda\|\mathbf w\|_1λ∥w∥1​: its diamond-shaped constraint region has corners on the axes, so solutions are often exactly zero, giving automatic feature selection. It has no closed form (use coordinate descent). Elastic net combines both.

Nonlinear features: linear regression is linear in w\mathbf ww, not in x\mathbf xx. Add x2x^2x2, x1x2x_1x_2x1​x2​, log⁡x\log xlogx, etc., and it fits curves.

# From scratch: closed form and gradient descent
rng = np.random.default_rng(0)
X = np.c_[np.ones(200), rng.normal(size=(200, 2))]
w_true = np.array([1.0, 2.0, -3.0]); y = X @ w_true + 0.5 * rng.normal(size=200)

w_closed = np.linalg.solve(X.T @ X, X.T @ y)            # never invert explicitly
w = np.zeros(3)
for _ in range(500):
    w -= 0.1 * (2 / len(y)) * X.T @ (X @ w - y)          # gradient of the mean squared error
print(w_closed, w)

from sklearn.linear_model import Ridge, Lasso
print(Lasso(alpha=0.1).fit(X[:, 1:], y).coef_)
