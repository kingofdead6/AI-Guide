Broadcasting rules

Compare shapes from the right. Two dimensions are compatible if they are equal or one of them is 1; the size-1 dimension is stretched. Missing leading dimensions count as 1.

import numpy as np
X  = np.random.randn(500, 3)               # (n, d)
mu = X.mean(axis=0)                        # (d,)   mean of each column
Z  = (X - mu) / X.std(axis=0)              # (n,d) - (d,) broadcasts -> standardized

# Pairwise squared distances between A (n,d) and B (m,d) without loops:
A, B = np.random.randn(100, 3), np.random.randn(80, 3)
D = (A**2).sum(1)[:, None] + (B**2).sum(1)[None, :] - 2 * A @ B.T   # (100, 80)

# einsum: explicit index notation, great for attention-like ops
Q, K = np.random.randn(8, 16, 64), np.random.randn(8, 16, 64)       # (heads, seq, dim)
scores = np.einsum("hqd,hkd->hqk", Q, K)                            # (8, 16, 16)

rng = np.random.default_rng(42)            # reproducible randomness
Classic pitfallA shape (n,) array is not a column vector. y - y_hat with shapes (n,) and (n,1) silently broadcasts to (n,n) and your loss is garbage. Use .reshape(-1) or [:, None] deliberately, and assert shapes.

  1. Implement softmax over the rows of a matrix, numerically stable, with no loops.
    Solution
    def softmax(Z):
    Z = Z - Z.max(axis=1, keepdims=True)   # shift: doesn't change result, avoids overflow
    E = np.exp(Z)
    return E / E.sum(axis=1, keepdims=True)
