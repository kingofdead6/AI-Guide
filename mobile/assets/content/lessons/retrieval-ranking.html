Bi-encoders vs cross-encoders

A bi-encoder embeds query and document separately: fast, pre-computable, used for retrieval. A cross-encoder reads query and document together through one Transformer and outputs a relevance score: much more accurate, but must run per pair. Standard pattern: retrieve 50–100 candidates cheaply, rerank with a cross-encoder, keep the top 5–10.

Query-side improvements

Query rewriting (fix typos, expand acronyms, resolve "it" from chat history), multi-query (generate several phrasings and fuse results), HyDE (embed a hypothetical answer instead of the question), and metadata filters (date, source, language, user permissions).

from rank_bm25 import BM25Okapi
from sentence_transformers import CrossEncoder
bm25 = BM25Okapi([d.lower().split() for d in docs])
bm25_rank = np.argsort(-bm25.get_scores("sleepy cats".split()))
dense_rank = ids[0]

def rrf(rankings, k=60):
    scores = {}
    for ranking in rankings:
        for r, doc_id in enumerate(ranking):
            scores[doc_id] = scores.get(doc_id, 0) + 1 / (k + r + 1)
    return sorted(scores, key=scores.get, reverse=True)
candidates = rrf([bm25_rank, dense_rank])

reranker = CrossEncoder("cross-encoder/ms-marco-MiniLM-L-6-v2")
pair_scores = reranker.predict([("sleepy cats", docs[i]) for i in candidates])
final = [candidates[i] for i in np.argsort(-pair_scores)]
