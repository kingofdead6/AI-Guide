Collaborative filtering and matrix factorization

From a sparse user × item interaction matrix, learn a vector per user and per item so their dot product predicts the interaction:

Solved with SGD or alternating least squares. Most real feedback is implicit (clicks, watches, purchases) with no explicit negatives; the BPR loss learns to rank an observed item iii above a sampled unobserved item jjj: −log⁡σ(r^ui−r^uj)-\log\sigma(\hat r_{ui}-\hat r_{uj})−logσ(r^ui​−r^uj​).

Modern multi-stage architecture

Candidate generation must search millions of items in milliseconds, so it uses a two-tower model: user and item encoders trained with an in-batch softmax (the InfoNCE loss from Vision Transformers, CLIP & Self-Supervised Vision), with item vectors pre-computed in an ANN index. Ranking scores a few hundred candidates with a heavier model using rich cross features (GBDT, Wide & Deep, DCN, DLRM-style networks, or Transformers over the user's recent history), predicting several objectives (click, watch time, purchase) combined into one score. Re-ranking applies diversity, freshness, fairness and business rules.

Problems that make recsys hard

  • Cold start: new users and items have no history; use content features and popularity priors.
  • Feedback loops and popularity bias: the model only learns from what it showed. Use exploration (bandits) and counterfactual evaluation.
  • Offline/online mismatch: offline Recall@k and NDCG don't always predict online wins; A/B tests decide.
  • Position bias: items shown higher get more clicks regardless of quality; model or correct it.
import torch, torch.nn as nn, torch.nn.functional as F
class MF(nn.Module):
    def __init__(self, n_users, n_items, d=64):
        super().__init__()
        self.U, self.I = nn.Embedding(n_users, d), nn.Embedding(n_items, d)
        self.bu, self.bi = nn.Embedding(n_users, 1), nn.Embedding(n_items, 1)
        nn.init.normal_(self.U.weight, std=0.01); nn.init.normal_(self.I.weight, std=0.01)
    def forward(self, u, i):
        return (self.U(u) * self.I(i)).sum(-1) + self.bu(u).squeeze(-1) + self.bi(i).squeeze(-1)

def bpr_loss(model, u, pos, neg):                     # implicit feedback
    return -F.logsigmoid(model(u, pos) - model(u, neg)).mean()
