Eigendecomposition

Av=λv(v≠0),det⁡(A−λI)=0\mathbf{Av}=\lambda\mathbf{v}\quad(\mathbf{v}\ne\mathbf{0}),\qquad \det(\mathbf{A}-\lambda\mathbf{I})=0Av=λv(v=0),det(A−λI)=0

An eigenvector keeps its direction under A\mathbf{A}A; it is only scaled by λ\lambdaλ. Spectral theorem: a real symmetric matrix has real eigenvalues and orthonormal eigenvectors, so

A=QΛQ⊤,Ak=QΛkQ⊤.\mathbf{A}=\mathbf{Q}\boldsymbol{\Lambda}\mathbf{Q}^\top,\qquad \mathbf{A}^k=\mathbf{Q}\boldsymbol{\Lambda}^k\mathbf{Q}^\top .A=QΛQ⊤,Ak=QΛkQ⊤.

A symmetric matrix is PSD exactly when all λi≥0\lambda_i\ge0λi​≥0. The power formula shows why repeated multiplication explodes if ∣λ∣>1|\lambda|\gt1∣λ∣>1 and vanishes if ∣λ∣<1|\lambda|\lt1∣λ∣<1: this is the vanishing/exploding gradient problem in RNNs (Recurrent Networks, LSTMs & GRUs).

Eckart–Young theorem. The best rank-kkk approximation of A\mathbf{A}A (in Frobenius or spectral norm) is the truncated SVD

Ak=∑i=1kσiuivi⊤,∥A−Ak∥F=∑i>kσi2.\mathbf{A}_k=\sum_{i=1}^{k}\sigma_i\mathbf{u}_i\mathbf{v}_i^\top,\qquad \|\mathbf{A}-\mathbf{A}_k\|_F=\sqrt{\textstyle\sum_{i\gt k}\sigma_i^2}.Ak​=i=1∑k​σi​ui​vi⊤​,∥A−Ak​∥F​=∑i>k​σi2​​.

The condition number κ=σmax⁡/σmin⁡\kappa=\sigma_{\max}/\sigma_{\min}κ=σmax​/σmin​ measures how badly a matrix distorts space. High κ\kappaκ means slow gradient descent and numerical instability (Optimization: Gradient Descent to Adam).

Where ML uses itPCA (Unsupervised Learning: k-Means, GMMs, EM & PCA) is an SVD of centered data. LoRA (Fine-Tuning, LoRA & Quantization) assumes weight updates are low-rank. Matrix factorization recommenders, latent semantic analysis, embedding compression and model compression all rely on low-rank approximation.
A = np.random.randn(100, 50)
U, S, Vt = np.linalg.svd(A, full_matrices=False)
k = 10
A_k = U[:, :k] @ np.diag(S[:k]) @ Vt[:k]
err = np.linalg.norm(A - A_k)             # Frobenius norm
print(np.isclose(err, np.sqrt((S[k:]**2).sum())))   # True (Eckart–Young)
