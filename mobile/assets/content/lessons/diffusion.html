Faster samplers (DDIM, DPM-Solver) need tens of steps instead of a thousand. Flow matching is a closely related, increasingly popular formulation that learns a velocity field transporting noise to data along simple paths.

Conditioning and guidance

Condition on text via cross-attention to a text encoder's embeddings. Classifier-free guidance: train with the condition randomly dropped, then at sampling time extrapolate

ϵ~=ϵθ(xt,∅)+w(ϵθ(xt,c)−ϵθ(xt,∅))\tilde{\boldsymbol\epsilon}=\boldsymbol\epsilon_\theta(\mathbf x_t,\varnothing)+w\big(\boldsymbol\epsilon_\theta(\mathbf x_t,c)-\boldsymbol\epsilon_\theta(\mathbf x_t,\varnothing)\big)ϵ~=ϵθ​(xt​,∅)+w(ϵθ​(xt​,c)−ϵθ​(xt​,∅))

with w>1w\gt1w>1 for stronger prompt adherence at some cost in diversity. Latent diffusion runs all of this in a VAE's compressed latent space, which makes high resolutions affordable.

T = 1000
betas = torch.linspace(1e-4, 0.02, T)
alphas = 1 - betas; abar = torch.cumprod(alphas, 0)

def train_step(model, x0, opt):
    t = torch.randint(0, T, (x0.size(0),), device=x0.device)
    eps = torch.randn_like(x0)
    a = abar.to(x0.device)[t].view(-1, 1, 1, 1)
    xt = a.sqrt() * x0 + (1 - a).sqrt() * eps
    loss = F.mse_loss(model(xt, t), eps)
    opt.zero_grad(); loss.backward(); opt.step()
    return loss.item()

@torch.no_grad()
def sample(model, shape, device):
    x = torch.randn(shape, device=device)
    for t in reversed(range(T)):
        tt = torch.full((shape[0],), t, device=device)
        eps = model(x, tt)
        x = (x - betas[t] / (1 - abar[t]).sqrt() * eps) / alphas[t].sqrt()
        if t > 0: x = x + betas[t].sqrt() * torch.randn_like(x)
    return x
