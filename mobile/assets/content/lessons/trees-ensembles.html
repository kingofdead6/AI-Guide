Decision trees

Recursively split on the feature and threshold that most reduce impurity. For class proportions pkp_kpk​ in a node:

Gini=1−∑kpk2,Entropy=−∑kpklog⁡2pk,Gain=I(parent)−∑cncnI(c)\text{Gini}=1-\sum_kp_k^2,\qquad \text{Entropy}=-\sum_kp_k\log_2p_k,\qquad \text{Gain}=I(\text{parent})-\sum_{c}\frac{n_c}{n}I(c)Gini=1−k∑​pk2​,Entropy=−k∑​pk​log2​pk​,Gain=I(parent)−c∑​nnc​​I(c)

For regression, minimize the variance (MSE) within children. Trees need no scaling and handle interactions, but a deep tree overfits badly: high variance.

Bagging and random forests

Train BBB trees on bootstrap samples and average them. For BBB predictors, each with variance σ2\sigma^2σ2 and pairwise correlation ρ\rhoρ:

Var⁡(1B∑bTb)=ρσ2+1−ρBσ2\operatorname{Var}\Big(\frac1B\sum_bT_b\Big)=\rho\sigma^2+\frac{1-\rho}{B}\sigma^2Var(B1​b∑​Tb​)=ρσ2+B1−ρ​σ2

Averaging kills the second term; a random forest also shrinks ρ\rhoρ by letting each split consider only a random subset of features (often d\sqrt dd​). Out-of-bag samples give a free validation estimate.

Gradient boosting

Build an additive model stage by stage, each new tree correcting the current errors:

Fm(x)=Fm−1(x)+ν hm(x),hm fit to ri=−∂L(yi,F)∂F∣F=Fm−1(xi)F_m(\mathbf x)=F_{m-1}(\mathbf x)+\nu\,h_m(\mathbf x),\qquad h_m\ \text{fit to}\ r_i=-\frac{\partial\mathcal L(y_i,F)}{\partial F}\Big|_{F=F_{m-1}(\mathbf x_i)}Fm​(x)=Fm−1​(x)+νhm​(x),hm​ fit to ri​=−∂F∂L(yi​,F)​​F=Fm−1​(xi​)​

This is gradient descent in function space. For squared loss, the pseudo-residuals rir_iri​ are literally yi−Fm−1(xi)y_i-F_{m-1}(\mathbf x_i)yi​−Fm−1​(xi​). The learning rate ν\nuν (shrinkage, e.g. 0.05) trades more trees for better generalization.
