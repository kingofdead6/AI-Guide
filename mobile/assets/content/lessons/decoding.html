  • Temperature TTT: T→0T\to0T→0 approaches greedy (argmax); T=1T=1T=1 is the model's distribution; T>1T\gt1T>1 flattens it (more random).
  • Greedy: always take the argmax. Deterministic, but prone to repetition.
  • Beam search: keep the bbb most likely partial sequences. Good for translation, bland for open-ended text.
  • Top-k: sample only from the kkk most likely tokens.
  • Top-p (nucleus): sample from the smallest set whose cumulative probability is at least ppp. It adapts: few candidates when the model is confident, many when it isn't.
  • Repetition and frequency penalties, stop sequences, and constrained (grammar/JSON-schema) decoding are common extras.
@torch.no_grad()
def generate(model, idx, max_new=100, T=0.8, top_k=None, top_p=0.95):
    for _ in range(max_new):
        logits, _ = model(idx[:, -256:])            # crop to context window
        logits = logits[:, -1, :] / max(T, 1e-5)
        if top_k is not None:
            v, _ = torch.topk(logits, top_k)
            logits[logits < v[:, [-1]]] = float("-inf")
        probs = logits.softmax(-1)
        if top_p is not None:
            sp, si = probs.sort(descending=True)
            cum = sp.cumsum(-1)
            sp[(cum - sp) > top_p] = 0                  # drop tokens beyond the nucleus
            probs = torch.zeros_like(probs).scatter(-1, si, sp)
            probs /= probs.sum(-1, keepdim=True)
        nxt = torch.multinomial(probs, 1)
        idx = torch.cat([idx, nxt], dim=1)
    return idx
