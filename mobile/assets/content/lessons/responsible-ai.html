Fairness metrics (group AAA, prediction Y^\hat YY^)

  • Demographic parity: P(Y^=1∣A=a)P(\hat Y=1\mid A=a)P(Y^=1∣A=a) equal across groups.
  • Equal opportunity: equal true positive rates across groups.
  • Equalized odds: equal TPR and FPR across groups.

These criteria generally can't all hold at once when base rates differ, so choosing among them is a values decision, not only a technical one. Always evaluate performance per subgroup.

Explainability

SHAP attributes a prediction to features using Shapley values from cooperative game theory:

ϕi=∑S⊆F∖{i}∣S∣! (∣F∣−∣S∣−1)!∣F∣![f(S∪{i})−f(S)]\phi_i=\sum_{S\subseteq F\setminus\{i\}}\frac{|S|!\,(|F|-|S|-1)!}{|F|!}\Big[f(S\cup\{i\})-f(S)\Big]ϕi​=S⊆F∖{i}∑​∣F∣!∣S∣!(∣F∣−∣S∣−1)!​[f(S∪{i})−f(S)]

the average marginal contribution of feature iii over all orderings. Contributions sum to the prediction minus the baseline. Other tools: permutation importance, partial dependence plots, LIME, and for deep nets, gradient-based saliency (integrated gradients) and attention or probing analyses (with care).

Privacy and security

Models can memorize training data (membership inference, extraction). Mitigations: data minimization, PII removal, access controls, and differential privacy (DP-SGD: clip per-example gradients and add calibrated noise). For LLM apps, defend against prompt injection and data exfiltration by treating all external content as untrusted and limiting what tools can do.
