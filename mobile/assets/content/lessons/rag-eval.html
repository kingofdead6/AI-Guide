Generation metrics

  • Faithfulness / groundedness: is every claim supported by the retrieved context?
  • Answer relevance: does it address the question?
  • Context precision: how much of the retrieved context was useful?
  • Correctness against a reference answer, when you have one.

Usually scored by an LLM judge with a rubric (frameworks like Ragas implement these), calibrated against a sample of human judgments.

def recall_at_k(results, relevant, k):     # results: ranked ids; relevant: set of ids
    return len(set(results[:k]) & relevant) / len(relevant)
def mrr(all_results, all_relevant):
    total = 0.0
    for res, rel in zip(all_results, all_relevant):
        total += next((1 / (i + 1) for i, d in enumerate(res) if d in rel), 0.0)
    return total / len(all_results)
