import pandas as pd, matplotlib.pyplot as plt, seaborn as sns
df = pd.read_csv("data.csv")
df.shape; df.head(); df.info(); df.describe(include="all")
df.isna().mean().sort_values(ascending=False)          # missing-value share per column
df["category"].value_counts(normalize=True)
df.groupby("city")["price"].agg(["mean", "median", "count"])
df.select_dtypes("number").corr()                      # linear correlations
sns.histplot(df["price"], log_scale=True); plt.show()
sns.boxplot(data=df, x="city", y="price"); plt.show()
df["date"] = pd.to_datetime(df["date"]); df.set_index("date")["price"].resample("M").mean()

EDA checklist

  1. Target: distribution, class balance, skew, outliers.
  2. Missingness: how much, and is it random or informative (e.g., "income missing" correlates with the label)?
  3. Types: numeric vs categorical vs text vs dates; cardinality of categoricals.
  4. Relationships: feature–target plots, correlations, groupby summaries.
  5. Leakage suspects: any feature that is too predictive, or only known after the outcome.
  6. Duplicates and time: repeated rows, drift over time, and whether a random split is even valid.
