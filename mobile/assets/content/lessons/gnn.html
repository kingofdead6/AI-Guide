Graphs as matrices

A graph with nnn nodes has an adjacency matrix A\mathbf AA (Aij=1A_{ij}=1Aij​=1 if nodes are connected), a degree matrix D=diag⁡(∑jAij)\mathbf D=\operatorname{diag}(\sum_jA_{ij})D=diag(∑j​Aij​) and node features X∈Rn×d\mathbf X\in\mathbb R^{n\times d}X∈Rn×d.

Message passing

Every GNN layer lets each node gather information from its neighbours:

hv(l+1)=ϕ(hv(l), ⨁u∈N(v)ψ(hu(l),hv(l),euv))\mathbf h_v^{(l+1)}=\phi\Big(\mathbf h_v^{(l)},\ \bigoplus_{u\in\mathcal N(v)}\psi\big(\mathbf h_u^{(l)},\mathbf h_v^{(l)},\mathbf e_{uv}\big)\Big)hv(l+1)​=ϕ(hv(l)​, u∈N(v)⨁​ψ(hu(l)​,hv(l)​,euv​))

The aggregator ⨁\bigoplus⨁ (sum, mean, max) is permutation-invariant, so the result doesn't depend on node ordering. Classic layers:

  • GCN: H′=σ(D~−1/2A~D~−1/2HW)\mathbf H'=\sigma\big(\tilde{\mathbf D}^{-1/2}\tilde{\mathbf A}\tilde{\mathbf D}^{-1/2}\mathbf H\mathbf W\big)H′=σ(D~−1/2A~D~−1/2HW) with A~=A+I\tilde{\mathbf A}=\mathbf A+\mathbf IA~=A+I (self-loops): a normalized neighbourhood average followed by a linear map.
  • GraphSAGE: concatenate a node's own vector with an aggregate of sampled neighbours; scales to huge graphs.
  • GAT: learn attention weights αuv\alpha_{uv}αuv​ over neighbours, like a Transformer restricted to graph edges. (A Transformer is a GNN on a fully connected graph.)

Tasks: node classification (fraud accounts), link prediction (recommendations, drug–target), graph classification (molecule toxicity; pool node vectors into one). Pitfalls: deep GNNs over-smooth (all nodes become similar), and information from far away gets squashed through bottleneck nodes, so most GNNs use 2–4 layers.

class GCNLayer(nn.Module):
    def __init__(self, d_in, d_out):
        super().__init__(); self.lin = nn.Linear(d_in, d_out)
    def forward(self, H, A):                          # A: dense (n, n) adjacency
        A_hat = A + torch.eye(A.shape[0], device=A.device)
        d = A_hat.sum(1).pow(-0.5)
        A_norm = d[:, None] * A_hat * d[None, :]      # D^-1/2 (A+I) D^-1/2
        return torch.relu(A_norm @ self.lin(H))
