Files and paths

Use pathlib instead of string paths: it works on Windows and Linux and reads clearly.

from pathlib import Path
import json, csv

root = Path("data")
(root / "raw").mkdir(parents=True, exist_ok=True)
for p in sorted(root.glob("**/*.jsonl")):      # recursive search
    print(p.name, p.suffix, p.stat().st_size)

text = Path("notes.txt").read_text(encoding="utf-8")
Path("out.txt").write_text("done\n", encoding="utf-8")

with open("config.json", encoding="utf-8") as f:   # always close files: use with
    cfg = json.load(f)
with open("results.json", "w", encoding="utf-8") as f:
    json.dump({"acc": 0.91}, f, ensure_ascii=False, indent=2)   # keep Arabic readable

with open("rows.csv", newline="", encoding="utf-8") as f:
    for row in csv.DictReader(f):                 # each row is a dict keyed by header
        print(row["label"])

Formats worth knowing: JSON for configs and API payloads, JSONL (one JSON object per line) for datasets and LLM fine-tuning data, CSV for simple tables, Parquet for large tabular data (see SQL & Data Engineering), and pickle only for trusted, temporary Python objects: loading a pickle runs arbitrary code.

Errors and exceptions

def parse_score(raw: str) -> float:
    try:
        value = float(raw)
    except ValueError as e:
        raise ValueError(f"score must be a number, got {raw!r}") from e
    if not 0 <= value <= 1:
        raise ValueError(f"score must be in [0, 1], got {value}")
    return value

try:
    s = parse_score("1.7")
except ValueError as e:
    print("bad input:", e)
else:
    print("ok", s)          # runs only if no exception
finally:
    print("always runs")    # cleanup
  • Catch the specific exceptions you can handle. A bare except: also swallows KeyboardInterrupt and hides real bugs.
  • Fail fast with clear messages at the boundary of your system (inputs, configs, API responses), so errors surface where they start.
  • Define your own exception classes for domain errors: class RateLimited(Exception): pass.
  • Use assert for internal sanity checks (shapes, invariants), not for validating user input: assertions can be disabled with python -O.

Logging instead of print

import logging
logging.basicConfig(level=logging.INFO, format="%(asctime)s %(levelname)s %(name)s: %(message)s")
log = logging.getLogger("train")
log.info("epoch %d loss %.4f", 3, 0.4123)
log.warning("learning rate %.0e looks high", 1e-1)

Command-line scripts

# train.py  — run with: python train.py --lr 1e-3 --epochs 5
import argparse
from pathlib import Path

def main():
    ap = argparse.ArgumentParser(description="Train a classifier")
    ap.add_argument("--lr", type=float, default=3e-4)
    ap.add_argument("--epochs", type=int, default=10)
    ap.add_argument("--data", type=Path, required=True)
    args = ap.parse_args()
    print(args.lr, args.epochs, args.data)

if __name__ == "__main__":     # only runs when executed directly, not when imported
    main()

Environments and dependencies

Every project gets its own isolated environment so library versions don't collide. Record exact versions so the project runs the same on another machine, in CI and in Docker.

# Standard library tooling
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install numpy pandas torch
pip freeze > requirements.txt      # pin exact versions

# uv: a fast modern alternative that manages Python versions, envs and lockfiles
uv init my-project && cd my-project
uv add numpy pandas torch          # updates pyproject.toml and uv.lock
uv run python train.py

# conda/mamba: useful when you need non-Python binaries (CUDA toolkits, GDAL)

Secrets (API keys) never go in code or git. Read them from environment variables, often loaded from a .env file that is listed in .gitignore:

import os
api_key = os.environ.get("LLM_API_KEY")
if not api_key:
    raise RuntimeError("Set LLM_API_KEY before running this script")

Modules and packages

A module is a .py file; a package is a folder of modules. Put reusable code in a package under src/ and import it from notebooks and scripts instead of copying cells around. A pyproject.toml declares the package name, dependencies and tool settings; pip install -e . makes it importable everywhere in the environment while you edit it.

my-project/
├── pyproject.toml
├── src/my_project/__init__.py
├── src/my_project/data.py
└── tests/test_data.py

Practice problem
  1. A teammate's script works on their laptop but crashes on the server with ModuleNotFoundError for a library they installed months ago. What should the project have, and why?
    Solution
    A pinned dependency file (requirements.txt with versions, or pyproject + lockfile) and a fresh virtual environment created from it. Then the server installs exactly the same versions, and missing or mismatched packages show up immediately instead of at runtime.
