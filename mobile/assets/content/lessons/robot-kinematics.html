The robotics stack

A robot repeatedly answers four questions: where am I (state estimation), where should I go (planning), how do I get there (control), and what is around me (perception). All of them are written in the language of coordinate frames and transforms, which is this lesson's subject.

Rotations

Forward kinematics

Forward kinematics maps joint angles to the end-effector pose. For the two-link planar arm:

x=l1cos⁡θ1+l2cos⁡(θ1+θ2),y=l1sin⁡θ1+l2sin⁡(θ1+θ2)x=l_1\cos\theta_1+l_2\cos(\theta_1+\theta_2),\qquad y=l_1\sin\theta_1+l_2\sin(\theta_1+\theta_2)x=l1​cosθ1​+l2​cos(θ1​+θ2​),y=l1​sinθ1​+l2​sin(θ1​+θ2​)

For a general serial arm, multiply one transform per joint: Tee=T1(θ1) T2(θ2)⋯Tn(θn)\mathbf T_{\text{ee}}=\mathbf T_1(\theta_1)\,\mathbf T_2(\theta_2)\cdots\mathbf T_n(\theta_n)Tee​=T1​(θ1​)T2​(θ2​)⋯Tn​(θn​). The Denavit–Hartenberg convention is a standard recipe for writing each Ti\mathbf T_iTi​ from four parameters.

Inverse kinematics

Inverse kinematics goes the other way: given a target position, find joint angles. For the two-link arm the law of cosines gives a closed form:

cos⁡θ2=x2+y2−l12−l222l1l2,θ1=atan2⁡(y,x)−atan2⁡ ⁣(l2sin⁡θ2,  l1+l2cos⁡θ2)\cos\theta_2=\frac{x^2+y^2-l_1^2-l_2^2}{2l_1l_2},\qquad \theta_1=\operatorname{atan2}(y,x)-\operatorname{atan2}\!\big(l_2\sin\theta_2,\;l_1+l_2\cos\theta_2\big)cosθ2​=2l1​l2​x2+y2−l12​−l22​​,θ1​=atan2(y,x)−atan2(l2​sinθ2​,l1​+l2​cosθ2​)

There are usually two solutions (elbow up and elbow down, from ±θ2\pm\theta_2±θ2​), and none when the target is out of reach (∣cos⁡θ2∣>1|\cos\theta_2|\gt1∣cosθ2​∣>1). Real arms with 6–7 joints rarely have neat closed forms, so IK is solved numerically with the Jacobian.

The Jacobian and differential kinematics

The Jacobian J(θ)=∂x/∂θ\mathbf J(\boldsymbol\theta)=\partial\mathbf x/\partial\boldsymbol\thetaJ(θ)=∂x/∂θ maps joint velocities to end-effector velocities, x˙=Jθ˙\dot{\mathbf x}=\mathbf J\dot{\boldsymbol\theta}x˙=Jθ˙. Numerical IK repeatedly takes a step that reduces the position error e=xtarget−x(θ)\mathbf e=\mathbf x_{\text{target}}-\mathbf x(\boldsymbol\theta)e=xtarget​−x(θ):

Δθ=J⊤(JJ⊤+λ2I)−1e(damped least squares)\Delta\boldsymbol\theta=\mathbf J^\top(\mathbf J\mathbf J^\top+\lambda^2\mathbf I)^{-1}\mathbf e\qquad\text{(damped least squares)}Δθ=J⊤(JJ⊤+λ2I)−1e(damped least squares)

It is the same idea as Gauss–Newton optimization, with damping λ\lambdaλ for stability near singularities: configurations where J\mathbf JJ loses rank (an outstretched arm cannot move further outward), so some directions need infinite joint speed.

import numpy as np
L1, L2 = 1.0, 0.8

def fk(th):
    t1, t2 = th
    return np.array([L1*np.cos(t1) + L2*np.cos(t1+t2), L1*np.sin(t1) + L2*np.sin(t1+t2)])

def jacobian(th):
    t1, t2 = th
    return np.array([[-L1*np.sin(t1) - L2*np.sin(t1+t2), -L2*np.sin(t1+t2)],
                     [ L1*np.cos(t1) + L2*np.cos(t1+t2),  L2*np.cos(t1+t2)]])

def ik(target, th=np.array([0.3, 0.3]), lam=0.05, iters=200):
    for _ in range(iters):
        e = target - fk(th)
        if np.linalg.norm(e) < 1e-6:
            break
        J = jacobian(th)
        th = th + J.T @ np.linalg.solve(J @ J.T + lam**2 * np.eye(2), e)
    return th

th = ik(np.array([1.2, 0.9]))
print(th, fk(th))          # angles that put the hand at (1.2, 0.9)

Mobile robots

A wheeled robot's pose is (x,y,θ)(x, y, \theta)(x,y,θ). A differential-drive robot (two powered wheels) with forward speed vvv and turn rate ω\omegaω moves as

x˙=vcos⁡θ,y˙=vsin⁡θ,θ˙=ω\dot x=v\cos\theta,\qquad \dot y=v\sin\theta,\qquad \dot\theta=\omegax˙=vcosθ,y˙​=vsinθ,θ˙=ω

It cannot move sideways: that is a nonholonomic constraint, and it is why parallel parking needs a planner. Integrating wheel speeds over time (odometry) drifts, which is why we need the state estimation of the next lesson.
