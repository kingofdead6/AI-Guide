The replay buffer D\mathcal DD breaks correlations between consecutive samples; the target network keeps the regression target from chasing itself. Double DQN picks a′a'a′ with the online network but evaluates it with the target network, reducing over-estimation.

Continuous control

DDPG and TD3 learn deterministic policies with a Q-critic. SAC maximizes reward plus policy entropy, J=E[∑trt+αH(π(⋅∣st))]J=\mathbb E\big[\sum_t r_t+\alpha\mathcal H(\pi(\cdot\mid s_t))\big]J=E[∑t​rt​+αH(π(⋅∣st​))], which keeps exploration alive and is very sample-efficient for robotics simulators.

Planning: MCTS and AlphaZero

With a model of the environment (a game's rules, or a learned world model), Monte Carlo tree search repeatedly selects actions by an upper-confidence rule, expands, evaluates and backs up values:

a∗=arg⁡max⁡a [Q(s,a)+c P(s,a) N(s)1+N(s,a)]a^*=\arg\max_a\ \Big[Q(s,a)+c\,P(s,a)\,\frac{\sqrt{N(s)}}{1+N(s,a)}\Big]a∗=argamax​ [Q(s,a)+cP(s,a)1+N(s,a)N(s)​​]

AlphaZero uses a network for the prior PPP and value, trains it on the improved policies that search produces, and repeats through self-play. Model-based RL more generally learns the dynamics and plans or trains inside the learned model.

Imitation and offline RL

Behaviour cloning is supervised learning on expert (state, action) pairs; simple but errors compound when the agent drifts into unseen states (DAgger fixes this by querying the expert on the agent's own states). Offline RL learns from a fixed dataset without interaction, using conservative methods so the policy doesn't exploit errors in Q-values for unseen actions. SFT of an LLM is behaviour cloning on demonstrations.

Why RL is hard in practiceReward design (agents exploit loopholes), sample inefficiency, sensitivity to hyperparameters and seeds, and the gap between simulation and the real world. # DQN core update
def dqn_update(q, q_target, batch, opt, gamma=0.99):
    s, a, r, s2, done = batch                              # tensors from the replay buffer
    q_sa = q(s).gather(1, a[:, None]).squeeze(1)
    with torch.no_grad():
        a2 = q(s2).argmax(1, keepdim=True)                 # double DQN: online picks...
        target = r + gamma * (1 - done) * q_target(s2).gather(1, a2).squeeze(1)   # ...target evaluates
    loss = F.smooth_l1_loss(q_sa, target)
    opt.zero_grad(); loss.backward(); opt.step()
    return loss.item()
# every N steps: q_target.load_state_dict(q.state_dict())
