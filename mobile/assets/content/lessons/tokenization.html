Word-level vocabularies explode and can't handle unseen words; character-level sequences are very long. Subwords sit in between: common words are single tokens, rare words split into pieces ("unbelievably" → "un", "believ", "ably").

Byte-Pair Encoding

  1. Start with a vocabulary of single characters (or all 256 bytes, so any text is representable).
  2. Count all adjacent symbol pairs in the corpus.
  3. Merge the most frequent pair into a new symbol; record the merge.
  4. Repeat until the vocabulary reaches the target size (e.g. 32k–200k).

To tokenize new text, apply the learned merges in order. WordPiece (BERT) picks merges by likelihood gain; Unigram (SentencePiece) starts large and prunes. In English a token averages about ¾ of a word. Languages underrepresented in tokenizer training, often including Arabic, need more tokens per word, which makes them more expensive and shortens the effective context.

from collections import Counter
def learn_bpe(words, n_merges):
    vocab = Counter(tuple(w) + ("</w>",) for w in words)       # words as symbol tuples
    merges = []
    for _ in range(n_merges):
        pairs = Counter()
        for sym, f in vocab.items():
            for a, b in zip(sym, sym[1:]): pairs[(a, b)] += f
        if not pairs: break
        best = max(pairs, key=pairs.get); merges.append(best)
        new_vocab = Counter()
        for sym, f in vocab.items():
            out, i = [], 0
            while i < len(sym):
                if i < len(sym) - 1 and (sym[i], sym[i+1]) == best:
                    out.append(sym[i] + sym[i+1]); i += 2
                else:
                    out.append(sym[i]); i += 1
            new_vocab[tuple(out)] += f
        vocab = new_vocab
    return merges
print(learn_bpe("low low low lower lowest newer newer wider".split(), 10))
