Scaled dot-product attention

Attention⁡(Q,K,V)=softmax⁡ ⁣(QK⊤dk+M)V\operatorname{Attention}(\mathbf Q,\mathbf K,\mathbf V)=\operatorname{softmax}\!\Big(\frac{\mathbf Q\mathbf K^\top}{\sqrt{d_k}}+\mathbf M\Big)\mathbf VAttention(Q,K,V)=softmax(dk​​QK⊤​+M)V

For a sequence X∈Rn×d\mathbf X\in\mathbb R^{n\times d}X∈Rn×d: Q=XWQ\mathbf Q=\mathbf X\mathbf W_QQ=XWQ​, K=XWK\mathbf K=\mathbf X\mathbf W_KK=XWK​, V=XWV\mathbf V=\mathbf X\mathbf W_VV=XWV​. Each token's query is compared with every token's key; the softmax turns scores into weights; the output is a weighted average of values. It is a soft, differentiable dictionary lookup.

  • Why dk\sqrt{d_k}dk​​? If query and key components are independent with variance 1, q⊤k=∑i=1dkqiki\mathbf q^\top\mathbf k=\sum_{i=1}^{d_k}q_ik_iq⊤k=∑i=1dk​​qi​ki​ has variance dkd_kdk​. Large scores saturate the softmax and its gradients vanish; dividing by dk\sqrt{d_k}dk​​ restores unit variance.
  • Causal mask M\mathbf MM: set Mij=−∞M_{ij}=-\inftyMij​=−∞ for j>ij\gt ij>i so token iii can't see the future. This is what makes a decoder a language model.
  • Cost: QK⊤\mathbf Q\mathbf K^\topQK⊤ is n×nn\times nn×n, so time and memory scale as O(n2d)O(n^2d)O(n2d). This is the main obstacle for long contexts (Inference Efficiency: KV Cache, FlashAttention & MoE).

Multi-head attention

MHA⁡(X)=Concat⁡(head1,…,headh)WO,headi=Attention⁡(XWQi,XWKi,XWVi)\operatorname{MHA}(\mathbf X)=\operatorname{Concat}(\text{head}_1,\dots,\text{head}_h)\mathbf W_O,\qquad \text{head}_i=\operatorname{Attention}(\mathbf X\mathbf W_Q^{i},\mathbf X\mathbf W_K^{i},\mathbf X\mathbf W_V^{i})MHA(X)=Concat(head1​,…,headh​)WO​,headi​=Attention(XWQi​,XWKi​,XWVi​)

Each head has dimension d/hd/hd/h and can learn a different relation (syntax, coreference, position). Total cost is about the same as one full-width head.

Positional information

Attention treats its input as a set: permute tokens and outputs permute the same way. Order must be injected. The original sinusoidal encoding:

PE(pos,2i)=sin⁡ ⁣(pos/100002i/d),PE(pos,2i+1)=cos⁡ ⁣(pos/100002i/d)PE_{(pos,2i)}=\sin\!\big(pos/10000^{2i/d}\big),\qquad PE_{(pos,2i+1)}=\cos\!\big(pos/10000^{2i/d}\big)PE(pos,2i)​=sin(pos/100002i/d),PE(pos,2i+1)​=cos(pos/100002i/d)

Modern LLMs mostly use RoPE (rotary embeddings): rotate each 2-D pair of query and key components by an angle proportional to position. Then qm⊤kn\mathbf q_m^\top\mathbf k_nqm⊤​kn​ depends only on the relative offset m−nm-nm−n.

The Transformer block (pre-norm, as in GPT-style models)

X←X+MHA⁡(LN⁡(X)),X←X+FFN⁡(LN⁡(X)),FFN⁡(x)=W2 ϕ(W1x)\mathbf X\leftarrow\mathbf X+\operatorname{MHA}(\operatorname{LN}(\mathbf X)),\qquad \mathbf X\leftarrow\mathbf X+\operatorname{FFN}(\operatorname{LN}(\mathbf X)),\qquad \operatorname{FFN}(\mathbf x)=\mathbf W_2\,\phi(\mathbf W_1\mathbf x)X←X+MHA(LN(X)),X←X+FFN(LN(X)),FFN(x)=W2​ϕ(W1​x)

Attention mixes information across tokens; the FFN (hidden size usually 4d4d4d) processes each token independently and holds much of the model's stored knowledge. Residuals and normalization make deep stacks trainable. Parameters per layer: about 4d24d^24d2 (attention) + 8d28d^28d2 (FFN) =12d2=12d^2=12d2.

Implementation

import math
class CausalSelfAttention(nn.Module):
    def __init__(self, d, n_heads, max_len=1024):
        super().__init__()
        assert d % n_heads == 0
        self.h, self.dk = n_heads, d // n_heads
        self.qkv = nn.Linear(d, 3 * d); self.proj = nn.Linear(d, d)
        self.register_buffer("mask", torch.tril(torch.ones(max_len, max_len)).bool())
    def forward(self, x):                                   # x: (B, T, d)
        B, T, d = x.shape
        q, k, v = self.qkv(x).split(d, dim=-1)
        q, k, v = (t.view(B, T, self.h, self.dk).transpose(1, 2) for t in (q, k, v))  # (B,h,T,dk)
        att = (q @ k.transpose(-2, -1)) / math.sqrt(self.dk)                          # (B,h,T,T)
        att = att.masked_fill(~self.mask[:T, :T], float("-inf")).softmax(dim=-1)
        y = (att @ v).transpose(1, 2).reshape(B, T, d)
        return self.proj(y)
        # In practice: F.scaled_dot_product_attention(q, k, v, is_causal=True) (FlashAttention kernel)

class Block(nn.Module):
    def __init__(self, d, n_heads):
        super().__init__()
        self.ln1, self.ln2 = nn.LayerNorm(d), nn.LayerNorm(d)
        self.attn = CausalSelfAttention(d, n_heads)
        self.ffn = nn.Sequential(nn.Linear(d, 4 * d), nn.GELU(), nn.Linear(4 * d, d))
    def forward(self, x):
        x = x + self.attn(self.ln1(x))
        return x + self.ffn(self.ln2(x))

class TinyGPT(nn.Module):
    def __init__(self, vocab, d=256, n_heads=8, n_layers=6, max_len=256):
        super().__init__()
        self.tok = nn.Embedding(vocab, d); self.pos = nn.Embedding(max_len, d)
        self.blocks = nn.Sequential(*[Block(d, n_heads) for _ in range(n_layers)])
        self.ln = nn.LayerNorm(d); self.head = nn.Linear(d, vocab, bias=False)
        self.head.weight = self.tok.weight                  # weight tying
    def forward(self, idx, targets=None):
        T = idx.shape[1]
        x = self.tok(idx) + self.pos(torch.arange(T, device=idx.device))
        logits = self.head(self.ln(self.blocks(x)))         # (B, T, vocab)
        loss = None if targets is None else F.cross_entropy(
            logits.view(-1, logits.size(-1)), targets.view(-1))
        return logits, loss

Train TinyGPT on a text file with targets = idx shifted by one position, using the loop from The Complete PyTorch Training Loop, and it will learn to produce text in that style. That's a real (small) language model.

  2. Why doesn't an encoder like BERT use a causal mask?
    Solution
    It isn't generating left to right. For understanding tasks each token should use context from both sides; BERT's training hides tokens by masking the input instead.
