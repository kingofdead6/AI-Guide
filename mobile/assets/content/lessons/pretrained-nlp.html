Fine-tuning an encoder for classification: take the final hidden state of [CLS] (or mean-pool all tokens), add a linear layer, and train everything end to end with a small learning rate (about 2e-5) for a few epochs. For token-level tasks like NER, put the classifier on every token's state.

Sentence embeddings (Sentence-BERT and successors): fine-tune encoders with contrastive objectives so that the cosine similarity of pooled vectors reflects meaning. These are the embedding models behind semantic search and RAG.

from transformers import AutoTokenizer, AutoModelForSequenceClassification, Trainer, TrainingArguments
from datasets import load_dataset
name = "distilbert-base-uncased"
tok = AutoTokenizer.from_pretrained(name)
ds = load_dataset("imdb").map(lambda b: tok(b["text"], truncation=True, max_length=256), batched=True)
model = AutoModelForSequenceClassification.from_pretrained(name, num_labels=2)
args = TrainingArguments("out", learning_rate=2e-5, per_device_train_batch_size=16,
                         num_train_epochs=2, eval_strategy="epoch", weight_decay=0.01)
Trainer(model=model, args=args, train_dataset=ds["train"], eval_dataset=ds["test"],
        tokenizer=tok).train()
