AUC has a clean meaning: the probability that a randomly chosen positive gets a higher score than a randomly chosen negative. For multi-class, macro averaging weights each class equally and micro averaging weights each example equally. A model is calibrated if, among predictions of 0.8, 80% are positive; check with a reliability diagram.

Practice problem
  1. 1,000 transactions, 10 are fraud. A model flags 20, catching 8 frauds. Compute precision, recall, F1 and accuracy.
    Solution
    TP = 8, FP = 12, FN = 2, TN = 978. Precision 0.40, recall 0.80, F1 ≈ 0.533, accuracy 0.986. A model that flags nothing would score 0.99 accuracy, which is why accuracy is misleading here.
