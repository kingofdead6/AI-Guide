Data parallelism

Each GPU holds a full model copy, processes a different slice of the batch, and gradients are averaged with an all-reduce before the optimizer step. A ring all-reduce moves about 2N−1N2\frac{N-1}{N}2NN−1​ times the gradient size per GPU, nearly independent of the number of GPUs. Overlap communication with the backward pass (DDP does this automatically).

Sharding: ZeRO and FSDP

Plain data parallelism replicates weights, gradients and optimizer states on every GPU (16 bytes/parameter with Adam, Fine-Tuning, LoRA & Quantization). ZeRO shards them across GPUs: stage 1 shards optimizer states, stage 2 also gradients, stage 3 (= PyTorch FSDP) also the weights, which are gathered layer by layer just in time.

Model parallelism

  • Tensor parallelism: split each weight matrix across GPUs (column-split the first FFN matrix, row-split the second, so only one all-reduce per block is needed). Needs very fast links, so it stays within a node (NVLink).
  • Pipeline parallelism: different layers on different GPUs; micro-batches keep stages busy. With ppp stages and mmm micro-batches the idle "bubble" fraction is about (p−1)/(m+p−1)(p-1)/(m+p-1)(p−1)/(m+p−1).
  • Sequence / context parallelism splits long sequences; expert parallelism places MoE experts on different GPUs.
  • Large runs combine them ("3D parallelism"): tensor parallel within a node, pipeline across nodes, data parallel/FSDP over everything.

Memory savers and practicalities

Activation checkpointing stores only some activations and recomputes the rest during backward (~30% more compute for much less memory). Gradient accumulation simulates large batches. Mixed precision everywhere. At scale, hardware fails: checkpoint frequently and make jobs resumable.

# train_ddp.py — launch with:  torchrun --nproc_per_node=4 train_ddp.py
import os, torch, torch.distributed as dist
from torch.nn.parallel import DistributedDataParallel as DDP
from torch.utils.data.distributed import DistributedSampler

dist.init_process_group("nccl")
rank = int(os.environ["LOCAL_RANK"]); torch.cuda.set_device(rank)
model = DDP(build_model().cuda(rank), device_ids=[rank])
sampler = DistributedSampler(dataset)                        # each rank gets a different shard
loader = torch.utils.data.DataLoader(dataset, batch_size=32, sampler=sampler)
opt = torch.optim.AdamW(model.parameters(), lr=3e-4)
for epoch in range(10):
    sampler.set_epoch(epoch)                                 # reshuffle differently each epoch
    for x, y in loader:
        loss = loss_fn(model(x.cuda(rank)), y.cuda(rank))
        opt.zero_grad(); loss.backward(); opt.step()         # gradients all-reduced during backward
    if rank == 0: torch.save(model.module.state_dict(), f"ckpt_{epoch}.pt")
dist.destroy_process_group()
