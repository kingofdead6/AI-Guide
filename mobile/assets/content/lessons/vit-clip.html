Vision Transformer (ViT)

Split an H×WH\times WH×W image into P×PP\times PP×P patches, giving N=HW/P2N=HW/P^2N=HW/P2 tokens (224×224 with P=16P=16P=16 gives 196). Flatten each patch, project it linearly to ddd dimensions, add position embeddings and a learnable [CLS] token, and run a standard Transformer encoder. ViTs have weaker built-in assumptions than CNNs (no locality bias), so they need more data or strong pretraining, but they scale extremely well.

CLIP: contrastive image–text learning

Train an image encoder and a text encoder so matching pairs have high cosine similarity. For a batch of NNN pairs with normalized embeddings ui\mathbf u_iui​ (image) and vj\mathbf v_jvj​ (text) and temperature τ\tauτ:

This is the InfoNCE loss: cross-entropy where the "correct class" is the matching pair and every other item in the batch is a negative. The same loss trains text embedding models for RAG (Embeddings & Vector Search). Zero-shot classification: embed "a photo of a {label}" for each label and pick the one closest to the image.

def info_nce(img_emb, txt_emb, tau=0.07):
    img = F.normalize(img_emb, dim=-1); txt = F.normalize(txt_emb, dim=-1)
    logits = img @ txt.T / tau                       # (N, N) similarity matrix
    labels = torch.arange(len(img), device=img.device)
    return (F.cross_entropy(logits, labels) + F.cross_entropy(logits.T, labels)) / 2

Self-supervised vision

SimCLR (two augmentations of the same image are positives), DINO (student–teacher self-distillation), MAE (mask 75% of patches, reconstruct them). These learn strong features without labels. Foundation models like SAM (promptable segmentation) and vision-language models (an image encoder feeding an LLM) are built on these ideas.
