Membership tests show why the choice matters: x in my_list scans the whole list, O(n); x in my_set hashes once, O(1). Checking 100,000 tokens against a 50,000-word vocabulary stored as a list takes billions of comparisons; as a set it takes 100,000 hash lookups.

Lists

tokens = ["the", "cat", "sat", "on", "the", "mat"]
tokens[0], tokens[-1]        # 'the', 'mat'   (negative indexes count from the end)
tokens[1:4]                  # ['cat', 'sat', 'on']   (slices: start inclusive, end exclusive)
tokens[::2]                  # every second item
tokens.append("today")       # O(1) at the end
tokens.insert(0, "<s>")      # O(n): shifts everything
tokens.pop()                 # remove and return the last item
sorted(tokens, key=len, reverse=True)   # new sorted list; tokens.sort() sorts in place
batches = [tokens[i:i + 2] for i in range(0, len(tokens), 2)]   # chunk into pairs

Dictionaries

config = {"lr": 3e-4, "batch_size": 32}
config["epochs"] = 10                   # add or overwrite
config.get("warmup", 0)                 # default when the key is missing
for key, value in config.items():
    print(key, value)

# Counting words: three equivalent ways, from manual to idiomatic
counts = {}
for w in tokens:
    counts[w] = counts.get(w, 0) + 1

from collections import Counter, defaultdict
counts = Counter(tokens)                # Counter({'the': 2, 'cat': 1, ...})
counts.most_common(2)

by_length = defaultdict(list)           # missing keys start as an empty list
for w in tokens:
    by_length[len(w)].append(w)

vocab = {w: i for i, w in enumerate(sorted(set(tokens)))}   # word -> id
inv_vocab = {i: w for w, i in vocab.items()}                 # id -> word

Keys must be hashable (immutable): strings, numbers, tuples. A list cannot be a key; convert it to a tuple.

Comprehensions

A comprehension builds a container from an iterable in one readable expression:

squares = [x * x for x in range(10)]
evens = [x for x in range(10) if x % 2 == 0]
lengths = {w: len(w) for w in tokens}
first_letters = {w[0] for w in tokens}
matrix = [[i * j for j in range(3)] for i in range(3)]   # nested: rows of columns
flat = [v for row in matrix for v in row]                 # flatten (outer loop first)

Use comprehensions for simple transforms and filters. When the logic needs several statements, a normal loop is clearer.

Mutability and aliasing

Assignment never copies. b = a makes a second name for the same list, so changing b changes a. This surprises everyone once, and it is the same rule that makes NumPy slices views of the original array.

a = [1, 2, 3]
b = a             # alias
c = a.copy()      # shallow copy (also list(a) or a[:])
b.append(4)
print(a, c)       # [1, 2, 3, 4] [1, 2, 3]

grid = [[0] * 3] * 3      # BUG: three references to one inner list
grid[0][0] = 1
print(grid)               # [[1, 0, 0], [1, 0, 0], [1, 0, 0]]
grid = [[0] * 3 for _ in range(3)]   # correct: three separate lists

import copy
nested = {"layers": [64, 32]}
deep = copy.deepcopy(nested)         # copies inner objects too

Use is to test identity (same object) and == to test equality (same value).

Practice problems
  1. You have 1 million user IDs in a list and need to check 1 million queries against it. Why is this slow and how do you fix it?
    Solution
    Each in on a list is O(n), so the total is about 101210^{12}1012 comparisons. Convert to a set once (O(n)), then each query is O(1): about 2×1062\times10^62×106 operations total.
  2. Write a dict comprehension that maps each word to its position of first occurrence in tokens.
    Solution
    {w: i for i, w in reversed(list(enumerate(tokens)))}: iterating backwards lets the earliest index overwrite later ones. A clearer loop: pos = {}; for i, w in enumerate(tokens): pos.setdefault(w, i).
