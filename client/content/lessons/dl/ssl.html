The contrastive loss (NT-Xent / InfoNCE)

For a batch of \(N\) items, create two augmented views each (2N embeddings, normalized). For a positive pair \((i,j)\):

$$\ell_{i,j}=-\log\frac{\exp(\operatorname{sim}(\mathbf z_i,\mathbf z_j)/\tau)}{\sum_{k\ne i}\exp(\operatorname{sim}(\mathbf z_i,\mathbf z_k)/\tau)}$$

The danger in joint-embedding methods is collapse: mapping everything to the same vector trivially makes views agree. Negatives (contrastive), stop-gradient with a momentum teacher (BYOL/DINO), or variance/covariance regularizers prevent it. The augmentations define what the model learns to ignore (crop, color, blur for images).

Evaluating representations: freeze the encoder and train a linear classifier on top (linear probe), or check kNN accuracy and few-shot transfer.

def nt_xent(z1, z2, tau=0.2):                  # z1, z2: (N, d) two views of the same N items
    z = F.normalize(torch.cat([z1, z2]), dim=1)   # (2N, d)
    sim = z @ z.T / tau
    sim.fill_diagonal_(float("-inf"))             # exclude self-similarity
    N = z1.shape[0]
    targets = torch.cat([torch.arange(N, 2 * N), torch.arange(0, N)]).to(z.device)
    return F.cross_entropy(sim, targets)
