From neuron to network

$$a=\phi(\mathbf w^\top\mathbf x+b),\qquad \mathbf h^{(l)}=\phi\big(\mathbf W^{(l)}\mathbf h^{(l-1)}+\mathbf b^{(l)}\big),\qquad \hat{\mathbf y}=\mathbf W^{(L)}\mathbf h^{(L-1)}+\mathbf b^{(L)}$$

Why nonlinearity is essential: without \(\phi\), stacking layers gives \(\mathbf W_2(\mathbf W_1\mathbf x)=(\mathbf W_2\mathbf W_1)\mathbf x\), which is still one linear map. Depth would add nothing.

Activation functions

Name\(\phi(z)\)\(\phi'(z)\)Notes
Sigmoid\(\frac1{1+e^{-z}}\)\(\sigma(1-\sigma)\le\tfrac14\)Saturates; gates and binary outputs
Tanh\(\tanh z\)\(1-\tanh^2z\)Zero-centred; RNNs
ReLU\(\max(0,z)\)\(\mathbb 1[z\gt0]\)Default for CNNs/MLPs; neurons can "die"
Leaky ReLU\(\max(\alpha z,z)\)\(1\) or \(\alpha\)Fixes dying ReLU

Softmax\(\frac{e^{z_k}}{\sum_je^{z_j}}\)\(p_k(\delta_{kj}-p_j)\)Output layer for classes

Universal approximation

A network with one hidden layer and enough units can approximate any continuous function on a compact set arbitrarily well. That says such a network exists, not that SGD will find it or that it will generalize. In practice depth is far more parameter-efficient than width, because deep networks compose features hierarchically (edges → textures → parts → objects).

Practice problem
  1. Why does the sigmoid's maximum derivative of 1/4 cause trouble in a 20-layer network?
    Solution
    Backprop multiplies one activation derivative per layer. Even in the best case, \((1/4)^{20}\approx10^{-12}\): gradients reaching early layers vanish. ReLU's derivative of 1 (for active units) avoids this, which is a big reason deep learning took off after 2010.
