Linear attention

Replace \(\operatorname{softmax}(\mathbf q^\top\mathbf k)\) by a kernel \(\phi(\mathbf q)^\top\phi(\mathbf k)\). Associativity then lets us compute \(\phi(\mathbf Q)\big(\phi(\mathbf K)^\top\mathbf V\big)\) in \(O(nd^2)\) instead of \(O(n^2d)\). In causal form the running sum \(\mathbf S_t=\mathbf S_{t-1}+\phi(\mathbf k_t)\mathbf v_t^\top\) is a recurrence with a fixed-size state: constant memory per generated token.

State space models

A continuous linear system \(\mathbf h'(t)=\mathbf A\mathbf h(t)+\mathbf Bx(t),\ y(t)=\mathbf C\mathbf h(t)\), discretized with step \(\Delta\), becomes

$$\mathbf h_t=\bar{\mathbf A}\mathbf h_{t-1}+\bar{\mathbf B}x_t,\qquad y_t=\mathbf C\mathbf h_t,\qquad \bar{\mathbf A}=e^{\Delta\mathbf A}$$
  • As a recurrence: O(1) memory per step at inference, like an RNN.
  • Unrolled, it is a convolution of the input with kernel \((\mathbf C\bar{\mathbf B},\mathbf C\bar{\mathbf A}\bar{\mathbf B},\mathbf C\bar{\mathbf A}^2\bar{\mathbf B},\dots)\): parallel training like a CNN.
  • Careful initialization of \(\mathbf A\) (S4) gives long memory without vanishing gradients.
  • Selective SSMs (Mamba): make \(\Delta,\mathbf B,\mathbf C\) depend on the input, so the model can choose what to remember or ignore, computed with a hardware-aware parallel scan.

Pure SSMs can struggle with exact recall (copying a phone number from far back), which attention does easily. Many recent long-context models are hybrids that interleave a few attention layers with many SSM or linear-attention layers. Other efficient options: sliding-window and sparse attention, and grouped-query attention to shrink the KV cache ([[inference]]).

def ssm_scan(x, A_bar, B_bar, C):                 # x: (T,), diagonal A_bar: (N,)
    h = torch.zeros_like(A_bar); ys = []
    for t in range(len(x)):                       # sequential form (inference)
        h = A_bar * h + B_bar * x[t]
        ys.append((C * h).sum())
    return torch.stack(ys)
# Training uses the equivalent convolution or a parallel associative scan over t.
