Why Python for AI

Python is slow at raw arithmetic, yet almost every AI system is written in it. The reason is that Python is the glue: the heavy maths runs inside libraries written in C, C++, CUDA or Rust (NumPy, PyTorch, tokenizers), and Python orchestrates them with readable code. Your job is to write clear Python that hands big chunks of work to those libraries.

The rule of thumb

A Python loop runs roughly 10–100 million simple operations per second. A vectorized library call can do billions. Write the logic in Python; push the number crunching into libraries.

Control flow

Indentation is the syntax: a block is everything indented under a line ending in a colon.

score = 0.83
if score >= 0.9:
    grade = "excellent"
elif score >= 0.6:
    grade = "pass"
else:
    grade = "retry"

for epoch in range(3):            # 0, 1, 2
    print("epoch", epoch)

loss, step = 10.0, 0
while loss > 1.0 and step < 100:
    loss *= 0.8
    step += 1

for i, word in enumerate(["the", "cat", "sat"]):   # index and value together
    print(i, word)
for a, b in zip([1, 2, 3], [10, 20, 30]):           # walk two sequences in step
    print(a * b)

Truthiness: empty containers, 0, 0.0, "" and None count as false in an if. So if items: means "if the list is not empty".

Functions

def accuracy(preds, labels, *, ignore_index=None):
    """Share of predictions that match the labels.

    The * makes ignore_index keyword-only, so calls stay readable.
    """
    pairs = [(p, y) for p, y in zip(preds, labels) if y != ignore_index]
    if not pairs:
        return 0.0
    return sum(p == y for p, y in pairs) / len(pairs)

print(accuracy([1, 0, 1], [1, 1, 1]))                     # 0.666...
print(accuracy([1, 0, 1], [1, -1, 1], ignore_index=-1))   # 1.0
  • Default arguments are evaluated once, when the function is defined. Never use a mutable default like def f(x, cache=[]): the same list is shared by every call. Use cache=None and create it inside.
  • *args collects extra positional arguments into a tuple and **kwargs extra keyword arguments into a dict. This is how wrappers forward arguments to libraries: model(**batch).
  • Functions are objects: you can pass them around, store them in dicts and return them. sorted(words, key=len) passes the function len.
  • Scope: names assigned inside a function are local. Reading a global works; assigning one needs global (and is usually a design smell).
square = lambda v: v * v                 # small anonymous function
activations = {"relu": lambda v: max(0.0, v), "identity": lambda v: v}
print(activations["relu"](-3.0))          # 0.0

def make_scheduler(base_lr, decay):
    def lr_at(step):                      # a closure: remembers base_lr and decay
        return base_lr * decay ** step
    return lr_at

sched = make_scheduler(0.1, 0.9)
print([round(sched(s), 4) for s in range(4)])   # [0.1, 0.09, 0.081, 0.0729]

Strings for text processing

NLP work starts with string handling. The methods you will use constantly:

s = "  The Transformer changed NLP.  "
s.strip().lower()                    # 'the transformer changed nlp.'
s.split()                            # ['The', 'Transformer', 'changed', 'NLP.']
" ".join(["a", "b", "c"])            # 'a b c'
"attention".startswith("att")        # True
"loss=0.32".replace("=", ": ")       # 'loss: 0.32'
"مرحبا".encode("utf-8")              # bytes: Arabic letters take 2 bytes each in UTF-8
len("مرحبا"), len("مرحبا".encode())  # (5, 10)
Text is Unicode, files are bytesAlways open text files with an explicit encoding="utf-8". Many bugs with Arabic, French accents or emoji come from relying on a platform default encoding.
Practice problems
  1. What does [i * i for i in range(5) if i % 2 == 0] produce?
    Solution
    [0, 4, 16]: squares of 0, 2 and 4.
  2. Why is def add_item(x, items=[]) a bug?
    Solution
    The default list is created once and shared, so items from earlier calls leak into later ones. Use items=None and if items is None: items = [].
