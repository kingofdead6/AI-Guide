Definitions

A vector \(\mathbf{x}\in\mathbb{R}^n\) is an ordered list of \(n\) real numbers. Vectors add component-wise and scale by scalars. Any expression \(\sum_i c_i\mathbf{v}_i\) is a linear combination; the set of all such combinations is the span. Vectors are linearly independent if none of them is a combination of the others. A basis is an independent set that spans the space, and its size is the dimension.

Dot product

$$\mathbf{x}\cdot\mathbf{y}=\mathbf{x}^\top\mathbf{y}=\sum_{i=1}^n x_i y_i=\|\mathbf{x}\|_2\,\|\mathbf{y}\|_2\cos\theta$$

It measures alignment: positive when vectors point the same way, zero when they are orthogonal, negative when they point in opposite directions.

Norms (lengths)

$$\|\mathbf{x}\|_1=\sum_i|x_i|,\qquad \|\mathbf{x}\|_2=\sqrt{\textstyle\sum_i x_i^2},\qquad \|\mathbf{x}\|_\infty=\max_i|x_i|,\qquad \|\mathbf{x}\|_p=\Big(\sum_i|x_i|^p\Big)^{1/p}$$

Cosine similarity and projection

$$\cos(\mathbf{x},\mathbf{y})=\frac{\mathbf{x}^\top\mathbf{y}}{\|\mathbf{x}\|_2\|\mathbf{y}\|_2}\in[-1,1],\qquad \operatorname{proj}_{\mathbf{y}}\mathbf{x}=\frac{\mathbf{x}^\top\mathbf{y}}{\|\mathbf{y}\|_2^2}\,\mathbf{y}$$

The bound \(|\cos|\le 1\) is the Cauchy–Schwarz inequality \(|\mathbf{x}^\top\mathbf{y}|\le\|\mathbf{x}\|\|\mathbf{y}\|\), which we will reuse several times.

Where ML uses itFeature vectors and embeddings. Cosine similarity is how RAG finds relevant documents ([[course:rag]]). Every neuron computes a dot product \(\mathbf{w}^\top\mathbf{x}\). L2 and L1 norms become weight decay and sparsity penalties ([[linear-regression]]). Attention scores are dot products between queries and keys ([[transformer]]).
import numpy as np
x = np.array([1.0, 2.0, 3.0]); y = np.array([4.0, -1.0, 2.0])
dot  = x @ y                                   # 8.0
l1   = np.abs(x).sum(); l2 = np.linalg.norm(x)
cos  = dot / (np.linalg.norm(x) * np.linalg.norm(y))
proj = (x @ y) / (y @ y) * y                   # projection of x onto y
Practice problems
  1. Compute the cosine similarity and angle between \((1,0,1)\) and \((0,1,1)\).
    Solution
    Dot product \(=1\), both norms \(=\sqrt2\), so \(\cos=1/2\) and \(\theta=60^\circ\).
  2. Show \(\|\mathbf{x}-\mathbf{y}\|^2=\|\mathbf{x}\|^2+\|\mathbf{y}\|^2-2\mathbf{x}^\top\mathbf{y}\). Deduce that for unit vectors, ranking neighbours by Euclidean distance gives the same order as ranking by cosine similarity.
    Solution
    Expand \((\mathbf{x}-\mathbf{y})^\top(\mathbf{x}-\mathbf{y})\). If \(\|\mathbf{x}\|=\|\mathbf{y}\|=1\) then \(\|\mathbf{x}-\mathbf{y}\|^2=2-2\cos(\mathbf{x},\mathbf{y})\), a decreasing function of cosine. This is why vector databases normalize embeddings and then use either metric interchangeably.
