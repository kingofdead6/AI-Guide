Multiplication and shapes

$$(\mathbf{AB})_{ij}=\sum_{k}A_{ik}B_{kj},\qquad \underbrace{\mathbf{A}}_{m\times n}\;\underbrace{\mathbf{B}}_{n\times p}=\underbrace{\mathbf{C}}_{m\times p}$$

Two views of \(\mathbf{Ax}\) that you should keep in mind at all times:

  • Row view: entry \(i\) is the dot product of row \(i\) with \(\mathbf{x}\).
  • Column view: \(\mathbf{Ax}=\sum_j x_j\,\mathbf{a}_j\), a linear combination of the columns. So \(\mathbf{Ax}=\mathbf{b}\) is solvable exactly when \(\mathbf{b}\) lies in the column space.

Essential facts

  • Not commutative: \(\mathbf{AB}\ne\mathbf{BA}\) in general. Associative: \((\mathbf{AB})\mathbf{C}=\mathbf{A}(\mathbf{BC})\).
  • Transpose: \((\mathbf{AB})^\top=\mathbf{B}^\top\mathbf{A}^\top\). Inverse: \((\mathbf{AB})^{-1}=\mathbf{B}^{-1}\mathbf{A}^{-1}\).
  • Rank = dimension of the column space = number of independent columns. A square matrix is invertible \(\iff\) full rank \(\iff \det\mathbf{A}\ne0\).
  • \(|\det\mathbf{A}|\) is the factor by which \(\mathbf{A}\) scales volumes. Zero determinant means some direction is squashed flat.
  • Trace \(\operatorname{tr}(\mathbf{A})=\sum_i A_{ii}\), and \(\operatorname{tr}(\mathbf{AB})=\operatorname{tr}(\mathbf{BA})\).

Most bugs in deep learning code are shape bugs, so write shapes next to every line.
B, d_in, d_out = 32, 784, 256
X = np.random.randn(B, d_in)
W = np.random.randn(d_out, d_in) * 0.01
b = np.zeros(d_out)
Y = X @ W.T + b          # (32, 256): one row per example
print(np.linalg.matrix_rank(W), np.trace(W @ W.T))
Practice problems
  1. Prove that \(\mathbf{A}^\top\mathbf{A}\) is positive semi-definite for any matrix \(\mathbf{A}\).
    Solution
    \(\mathbf{x}^\top\mathbf{A}^\top\mathbf{A}\mathbf{x}=(\mathbf{Ax})^\top(\mathbf{Ax})=\|\mathbf{Ax}\|^2\ge0\).
  2. A network maps 784 → 256 → 10 with biases. How many parameters?
    Solution
    \(784\cdot256+256+256\cdot10+10=200{,}960+2{,}570=203{,}530\).
