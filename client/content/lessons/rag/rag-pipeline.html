The pipeline

  1. Ingest: parse PDFs, HTML, docs; clean boilerplate; keep metadata (title, page, URL, date, access rights).
  2. Chunk: split into passages. Fixed-size with overlap (e.g. 300–800 tokens, 10–20% overlap) is a solid default; recursive splitting on headings and paragraphs keeps chunks coherent. Too small loses context; too large dilutes relevance.
  3. Embed and index chunks (dense, plus BM25 for hybrid).
  4. Retrieve top-k for each query, rerank, keep the best few.
  5. Generate: prompt with instructions, numbered sources, and the question. Ask the model to cite source numbers and to say when the sources don't contain the answer.
def chunk(text, size=800, overlap=150):            # character-based for simplicity
    out, start = [], 0
    while start < len(text):
        out.append(text[start:start + size]); start += size - overlap
    return out

class SimpleRAG:
    def __init__(self, encoder, llm):
        self.enc, self.llm, self.chunks, self.meta = encoder, llm, [], []
    def add(self, text, source):
        for c in chunk(text):
            self.chunks.append(c); self.meta.append(source)
        self.E = self.enc.encode(self.chunks, normalize_embeddings=True)
    def retrieve(self, q, k=5):
        qv = self.enc.encode([q], normalize_embeddings=True)[0]
        top = np.argsort(-(self.E @ qv))[:k]
        return [(self.chunks[i], self.meta[i]) for i in top]
    def answer(self, q):
        ctx = "\n\n".join(f"[{i+1}] ({src})\n{c}" for i, (c, src) in enumerate(self.retrieve(q)))
        prompt = ("Answer the question using only the sources below. Cite sources like [1]. "
                  "If the sources don't contain the answer, say so.\n\n"
                  f"<sources>\n{ctx}\n</sources>\n\nQuestion: {q}")
        return self.llm(prompt)

Making it good

  • Contextual chunks: prepend the document title and section heading (or an LLM-written one-line summary of where the chunk sits) to each chunk before embedding.
  • Parent-document retrieval: match on small chunks, but give the model the larger surrounding section.
  • Multi-hop questions: let the model issue follow-up searches (agentic RAG, 8.5).
  • Structured data: route numeric questions to SQL instead of text search. GraphRAG builds an entity graph for questions that span many documents.
  • Freshness and permissions: re-index on change; filter by the user's access rights at retrieval time.
