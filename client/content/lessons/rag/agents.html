The loop

  1. The model receives the goal, available tools (name, description, JSON schema for arguments), and history.
  2. It outputs either a final answer or a structured tool call.
  3. Your code executes the tool (search, SQL, code execution, an API) and appends the result.
  4. Repeat, with a step limit.

This "reason, act, observe" pattern is often called ReAct. Providers support native function calling, and the Model Context Protocol (MCP) standardizes how tools and data sources are exposed to models.

Design principles

  • Start with the simplest thing: a single LLM call, then a fixed workflow (prompt chaining, routing), and only then a free-form agent.
  • Write tool descriptions as carefully as prompts; return concise, informative errors so the model can recover.
  • Memory: short-term is the conversation context; long-term is a store the agent can write to and search.
  • Safety: least-privilege tools, human confirmation for irreversible actions (sending, paying, deleting), and treat tool outputs and web content as untrusted data, never instructions.
  • Evaluate on full tasks (success rate, steps, cost), not single turns.
import json
TOOLS = {
    "search_docs": lambda query: [c for c, _ in rag.retrieve(query, k=3)],
    "calculator":  lambda expression: eval(expression, {"__builtins__": {}}),   # demo only; never eval untrusted input in production
}
SYSTEM = ("You can use tools. Reply with JSON only: "
          '{"tool": name, "args": {...}} to call a tool, or {"answer": text} when done. '
          "Tools: search_docs(query), calculator(expression).")

def run_agent(goal, max_steps=6):
    history = [f"Goal: {goal}"]
    for _ in range(max_steps):
        reply = json.loads(llm(SYSTEM + "\n\n" + "\n".join(history)))
        if "answer" in reply:
            return reply["answer"]
        try:
            result = TOOLS[reply["tool"]](**reply["args"])
        except Exception as e:
            result = f"ERROR: {e}"
        history.append(f"Called {reply['tool']}({reply['args']}) -> {json.dumps(result)[:2000]}")
    return "Stopped: step limit reached."
