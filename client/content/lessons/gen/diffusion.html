Forward process (fixed, no learning)

$$q(\mathbf x_t\mid\mathbf x_{t-1})=\mathcal N\big(\sqrt{1-\beta_t}\,\mathbf x_{t-1},\ \beta_t\mathbf I\big),\qquad t=1,\dots,T$$

With \(\alpha_t=1-\beta_t\) and \(\bar\alpha_t=\prod_{s=1}^t\alpha_s\), composing Gaussians gives a closed form to jump straight to any step:

$$\mathbf x_t=\sqrt{\bar\alpha_t}\,\mathbf x_0+\sqrt{1-\bar\alpha_t}\,\boldsymbol\epsilon,\qquad\boldsymbol\epsilon\sim\mathcal N(\mathbf 0,\mathbf I)$$

As \(t\to T\), \(\bar\alpha_t\to0\) and \(\mathbf x_T\) is essentially pure Gaussian noise.

Training: predict the noise

A network \(\boldsymbol\epsilon_\theta(\mathbf x_t,t)\) (a U-Net or a Transformer) learns to predict the noise that was added. The simplified DDPM objective, derived from a variational bound like the VAE's:

$$\mathcal L=\mathbb E_{\mathbf x_0,\,t,\,\boldsymbol\epsilon}\Big[\big\|\boldsymbol\epsilon-\boldsymbol\epsilon_\theta\big(\sqrt{\bar\alpha_t}\mathbf x_0+\sqrt{1-\bar\alpha_t}\boldsymbol\epsilon,\ t\big)\big\|^2\Big]$$

Training is just regression with MSE: no adversary, very stable.

Sampling: reverse step by step

$$\mathbf x_{t-1}=\frac{1}{\sqrt{\alpha_t}}\Big(\mathbf x_t-\frac{\beta_t}{\sqrt{1-\bar\alpha_t}}\boldsymbol\epsilon_\theta(\mathbf x_t,t)\Big)+\sigma_t\mathbf z,\qquad \mathbf z\sim\mathcal N(\mathbf 0,\mathbf I)$$

Faster samplers (DDIM, DPM-Solver) need tens of steps instead of a thousand. Predicting noise is equivalent to estimating the score \(\nabla_{\mathbf x}\log p(\mathbf x_t)\), which links diffusion to score-based models. Flow matching is a closely related, increasingly popular formulation that learns a velocity field transporting noise to data along simple paths.

Conditioning and guidance

Condition on text via cross-attention to a text encoder's embeddings. Classifier-free guidance: train with the condition randomly dropped, then at sampling time extrapolate

$$\tilde{\boldsymbol\epsilon}=\boldsymbol\epsilon_\theta(\mathbf x_t,\varnothing)+w\big(\boldsymbol\epsilon_\theta(\mathbf x_t,c)-\boldsymbol\epsilon_\theta(\mathbf x_t,\varnothing)\big)$$

with \(w\gt1\) for stronger prompt adherence at some cost in diversity. Latent diffusion runs all of this in a VAE's compressed latent space, which makes high resolutions affordable.

T = 1000
betas = torch.linspace(1e-4, 0.02, T)
alphas = 1 - betas; abar = torch.cumprod(alphas, 0)

def train_step(model, x0, opt):
    t = torch.randint(0, T, (x0.size(0),), device=x0.device)
    eps = torch.randn_like(x0)
    a = abar.to(x0.device)[t].view(-1, 1, 1, 1)
    xt = a.sqrt() * x0 + (1 - a).sqrt() * eps
    loss = F.mse_loss(model(xt, t), eps)
    opt.zero_grad(); loss.backward(); opt.step()
    return loss.item()

@torch.no_grad()
def sample(model, shape, device):
    x = torch.randn(shape, device=device)
    for t in reversed(range(T)):
        tt = torch.full((shape[0],), t, device=device)
        eps = model(x, tt)
        x = (x - betas[t] / (1 - abar[t]).sqrt() * eps) / alphas[t].sqrt()
        if t > 0: x = x + betas[t].sqrt() * torch.randn_like(x)
    return x
