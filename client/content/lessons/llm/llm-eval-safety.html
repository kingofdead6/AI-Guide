Measuring capability

  • Benchmarks: knowledge (multiple choice), math, coding, long-context retrieval, tool use, agentic tasks. Beware contamination (test items leaked into training data) and saturation.
  • Coding pass@k, estimated without bias from \(n\) samples of which \(c\) pass: $$\text{pass@}k=1-\binom{n-c}{k}\Big/\binom{n}{k}$$
  • Pairwise human preference (arena-style) with Bradley–Terry / Elo ratings, and LLM-as-judge with calibrated rubrics.
  • For your own product, the only evaluation that really counts is a test set built from your real use cases ([[using-llms]]).

Safety

Risks include harmful assistance, hallucination, bias, privacy leakage, jailbreaks (prompts that bypass safety training) and prompt injection (instructions hidden in documents, web pages or tool outputs that hijack an agent). Mitigations stack: safety-focused training (RLHF, constitution-style AI feedback), input/output classifiers, least-privilege tools, human confirmation for consequential actions, red-teaming before release, and monitoring after.

Interpretability

  • Probing: train a linear classifier on hidden states to test whether information (e.g. sentiment, syntax) is linearly encoded.
  • Logit lens: apply the output head to intermediate layers to see how the prediction forms layer by layer.
  • Activation patching: copy activations from one run into another to find which components causally matter for a behaviour.
  • Sparse autoencoders: neurons are polysemantic, so learn an overcomplete dictionary of sparse "features" from activations: $$\mathcal L=\|\mathbf x-\mathbf W_d\,\mathbf f\|_2^2+\lambda\|\mathbf f\|_1,\qquad \mathbf f=\operatorname{ReLU}(\mathbf W_e\mathbf x+\mathbf b_e)$$ Many learned features turn out to be human-interpretable concepts, and amplifying them can steer behaviour.
from math import comb
def pass_at_k(n, c, k):
    return 1.0 if n - c < k else 1 - comb(n - c, k) / comb(n, k)
print(pass_at_k(n=20, c=3, k=1), pass_at_k(20, 3, 5))   # 0.15, ≈0.60
