Classification

MetricFormulaUse when
Accuracy\(\frac{TP+TN}{\text{all}}\)Balanced classes, equal error costs
Precision\(\frac{TP}{TP+FP}\)False positives are costly (spam filter)
Recall (TPR)\(\frac{TP}{TP+FN}\)False negatives are costly (disease screening)
F1\(\frac{2PR}{P+R}\)Need one number balancing P and R
ROC-AUCArea under TPR vs FPRRanking quality, threshold-free
PR-AUCArea under precision vs recallHeavy class imbalance
Log loss\(-\frac1n\sum\log p(y_i\mid\mathbf x_i)\)Probabilities must be calibrated

AUC has a clean meaning: the probability that a randomly chosen positive gets a higher score than a randomly chosen negative. For multi-class, macro averaging weights each class equally and micro averaging weights each example equally. A model is calibrated if, among predictions of 0.8, 80% are positive; check with a reliability diagram.

Regression

$$\text{MAE}=\tfrac1n\sum|y_i-\hat y_i|,\quad \text{RMSE}=\sqrt{\tfrac1n\sum(y_i-\hat y_i)^2},\quad R^2=1-\frac{\sum(y_i-\hat y_i)^2}{\sum(y_i-\bar y)^2}$$

RMSE punishes large errors more than MAE. \(R^2\) is the fraction of variance explained; it can be negative on test data if the model is worse than predicting the mean.

from sklearn.metrics import (classification_report, confusion_matrix, roc_auc_score,
                             average_precision_score, mean_absolute_error, r2_score)
proba = model.predict_proba(X_te)[:, 1]
pred = (proba >= 0.5).astype(int)          # tune this threshold on validation data
print(confusion_matrix(y_te, pred)); print(classification_report(y_te, pred))
print("ROC-AUC", roc_auc_score(y_te, proba), "PR-AUC", average_precision_score(y_te, proba))
Practice problem
  1. 1,000 transactions, 10 are fraud. A model flags 20, catching 8 frauds. Compute precision, recall, F1 and accuracy.
    Solution
    TP = 8, FP = 12, FN = 2, TN = 978. Precision 0.40, recall 0.80, F1 ≈ 0.533, accuracy 0.986. A model that flags nothing would score 0.99 accuracy, which is why accuracy is misleading here.
