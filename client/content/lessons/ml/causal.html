Potential outcomes

Each unit has two potential outcomes, \(Y(1)\) with treatment and \(Y(0)\) without; we only ever observe one. The average treatment effect is \(\text{ATE}=\mathbb E[Y(1)-Y(0)]\). Randomization makes treatment independent of the potential outcomes, so a simple difference in means estimates the ATE without bias.

Without randomization, a confounder \(Z\) that drives both treatment and outcome creates spurious correlation (Simpson's paradox is the extreme case, where a trend reverses once you condition on \(Z\)).

A/B testing done right

Sample size per group to detect an effect \(\delta\) with significance \(\alpha\) and power \(1-\beta\):

$$n\approx\frac{2\,(z_{1-\alpha/2}+z_{1-\beta})^2\,\sigma^2}{\delta^2}\qquad(\alpha=0.05,\ \text{power}=0.8\ \Rightarrow\ (1.96+0.84)^2\approx7.85)$$
  • Decide the primary metric, guardrail metrics and duration before starting. Don't stop early when the p-value dips below 0.05 ("peeking" inflates false positives) unless you use sequential testing.
  • Many metrics or variants → correct for multiple comparisons.
  • CUPED reduces variance by adjusting for each user's pre-experiment metric, so you need fewer users.
  • Watch for novelty effects, network effects between users, and sample ratio mismatch (unequal group sizes signal a bug).

When you can't randomize

Regression adjustment on measured confounders; propensity scores \(e(x)=P(T=1\mid x)\) for matching or inverse-probability weighting (weight treated units by \(1/e(x)\) and controls by \(1/(1-e(x))\)); difference-in-differences (compare changes over time against a control group); instrumental variables; regression discontinuity. Each rests on assumptions you must state. Uplift models predict the individual treatment effect to target interventions.

from scipy import stats
import numpy as np
# Sample size for a conversion-rate test: baseline 10%, detect +1 point absolute
p, delta = 0.10, 0.01
sigma2 = p * (1 - p)
n = 2 * (stats.norm.ppf(0.975) + stats.norm.ppf(0.8))**2 * sigma2 / delta**2
print(round(n))                                   # ≈ 14,100 users per group

# Analysis: two-proportion z-test
conv = np.array([1520, 1415]); users = np.array([14000, 14000])
pooled = conv.sum() / users.sum()
z = (conv[0] / users[0] - conv[1] / users[1]) / np.sqrt(pooled * (1 - pooled) * (2 / users[0]))
print(z, 2 * (1 - stats.norm.cdf(abs(z))))        # z ≈ 2.05, p ≈ 0.04
Practice problem
  1. Users who use feature X retain 20% better. Your manager wants to force everyone to use X. What do you say?
    Solution
    That's a correlation with a likely confounder: engaged users both discover X and retain better. Forcing X may do nothing or even hurt. Run a randomized experiment (e.g. prompt a random half of users toward X) and measure the effect on retention, or at least adjust for prior engagement.
