Video

A video is a tensor \(T\times H\times W\times C\). Approaches: 2D CNN per frame plus temporal pooling or an RNN; 3D convolutions over space and time; two-stream networks (RGB + optical flow); and video Transformers over spatio-temporal patches ("tubelets"). Compute is the main constraint, so sample frames sparsely and use factorized space/time attention.

Tracking

Tracking-by-detection: run a detector each frame, then associate detections to existing tracks. A Kalman filter predicts where each track moves; the Hungarian algorithm solves the assignment using IoU and appearance-embedding similarity (SORT / DeepSORT / ByteTrack). Used in sports analytics, traffic, retail and license-plate systems.

3D vision

  • Depth estimation from stereo pairs, or from a single image with a network (monocular depth).
  • Point clouds (LiDAR): PointNet applies a shared MLP to each point and a symmetric max-pool, making the result independent of point order.
  • Neural radiance fields (NeRF): an MLP maps a 3D position and viewing direction to density \(\sigma\) and colour \(\mathbf c\). A pixel is rendered by integrating along its camera ray: $$\hat C(\mathbf r)=\sum_{i}T_i\big(1-e^{-\sigma_i\delta_i}\big)\mathbf c_i,\qquad T_i=\exp\Big(-\sum_{j\lt i}\sigma_j\delta_j\Big)$$ The whole renderer is differentiable, so the scene is learned from photos alone.
  • 3D Gaussian splatting represents the scene as millions of small coloured Gaussians rasterized directly, rendering in real time.

OCR and document AI

Classic OCR = text detection (find word boxes) + recognition (a CNN/Transformer reading a crop, trained with CTC loss, [[speech]]). Documents also need layout understanding (tables, forms, reading order). Today, vision-language models can read a page image and output structured JSON directly; combine them with classic OCR for verifiable coordinates, and evaluate on character error rate and field-level accuracy. Arabic and mixed-script documents need models trained on those scripts: test before trusting.

# NeRF-style volume rendering along one ray (the core equation above)
def render_ray(sigmas, colors, deltas):          # (S,), (S, 3), (S,)
    alpha = 1 - torch.exp(-sigmas * deltas)
    T = torch.cumprod(torch.cat([torch.ones(1), 1 - alpha + 1e-10])[:-1], dim=0)
    weights = T * alpha
    return (weights[:, None] * colors).sum(0)    # pixel colour
