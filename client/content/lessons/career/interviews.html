Question bank (try first, then open)

Why use cross-entropy instead of MSE for classification?
It is the negative log-likelihood of a categorical model ([[estimation]]). With softmax its gradient is simply \(\mathbf p-\mathbf y\), so it doesn't vanish when the model is confidently wrong, whereas MSE through a sigmoid/softmax saturates and learns slowly. It also heavily penalizes confident mistakes.
L1 vs L2 regularization?
L2 (Gaussian prior) shrinks all weights smoothly and handles correlated features well. L1 (Laplace prior) drives many weights to exactly zero because its constraint region has corners on the axes: built-in feature selection. Elastic net mixes both.
Your training loss isn't decreasing. What do you check?
Initial loss ≈ ln(C)? Can it overfit one batch? Learning rate too high/low (sweep)? Data and labels aligned (visualize a batch)? Gradients flowing (norms per layer, no NaNs)? Correct loss input (logits vs probabilities)? Model in train mode, optimizer stepping the right parameters, zero_grad called? Normalization of inputs?
Why divide attention scores by √d_k?
With unit-variance components, \(\mathbf q^\top\mathbf k\) has variance \(d_k\). Large scores push softmax into saturation where gradients vanish. Scaling restores unit variance ([[transformer]]).
BatchNorm vs LayerNorm: why do Transformers use LayerNorm?
BatchNorm normalizes each feature across the batch, so it depends on batch size and statistics differ between training and inference; awkward for variable-length sequences and small batches. LayerNorm normalizes across features within each token, independent of the batch.
What is the KV cache and what does it cost?
During generation, keys and values of previous tokens are stored so each new token only computes its own. Memory = 2 × layers × KV heads × head dim × sequence length × batch × bytes. Grouped-query attention and quantized caches reduce it ([[inference]]).
RAG or fine-tuning?
RAG for knowledge that changes, must be cited, or is private and large. Fine-tuning for behaviour, format, style, or squeezing a smaller model to do a narrow task well. They combine: fine-tune a model to use retrieved context better.
How does LoRA work and why does it save memory?
Freeze \(\mathbf W_0\), learn \(\Delta\mathbf W=\mathbf{BA}\) with rank \(r\ll d\). Only \(r(d+k)\) parameters get gradients and optimizer states, so memory drops massively; \(\mathbf B=0\) at init so training starts from the pretrained model; the update can be merged after training.
Precision vs recall: how do you choose the threshold?
From costs: pick the threshold minimizing expected cost (FP cost × FP + FN cost × FN), or meet a constraint (e.g. 95% recall for screening, a fixed review capacity for fraud). Use a validation set and PR curve, not 0.5 by default.
ROC-AUC vs PR-AUC on imbalanced data?
ROC-AUC can look great with heavy imbalance because the false positive rate divides by a huge number of negatives. PR-AUC focuses on the positive class and reveals how many flagged items are actually positive.
Explain data leakage with an example.
Information unavailable at prediction time leaks into training: e.g. a "refund issued" feature in a churn model, target encoding computed on the full dataset, random splits on time series, or the same patient in train and test. Symptom: great offline metrics, poor production performance.
Adam vs SGD with momentum?
Adam adapts per-parameter step sizes from gradient magnitude history: robust defaults, fast progress, standard for Transformers (AdamW). SGD + momentum can generalize slightly better for some CNNs with careful tuning and uses less memory (no second-moment state).
Why do GBDTs often beat neural nets on tabular data?
Tabular features are heterogeneous, often non-smooth, with irrelevant columns; trees handle thresholds, missing values and mixed scales naturally and need little tuning. Neural nets shine with large data, unstructured inputs, or when learned embeddings matter.
How do you evaluate an LLM application?
A test set from real use cases with expected outputs or rubrics; deterministic checks (schema, unit tests, citations); LLM-as-judge validated against humans; component metrics (retrieval recall@k, faithfulness); online signals (resolution, thumbs, escalations); run it on every change and track cost and latency too.
How do you reduce hallucinations?
Ground answers in retrieved sources and require citations; allow "I don't know"; lower temperature for factual tasks; constrain outputs with schemas; verify with tools or a checker; improve retrieval quality; evaluate groundedness explicitly.
Vanishing gradients: causes and fixes?
Products of many derivatives smaller than 1 (saturating activations, deep or recurrent networks, poor init). Fixes: ReLU-family activations, He/Xavier init, residual connections, normalization layers, gating (LSTM/GRU), gradient clipping for the exploding case.
What does temperature do in sampling?
Divides logits by \(T\) before softmax: \(T\lt1\) sharpens toward greedy, \(T\gt1\) flattens toward uniform. It changes diversity, not the model's knowledge.
How many samples do you need for an A/B test?
Roughly \(n\approx 2(z_{1-\alpha/2}+z_{1-\beta})^2\sigma^2/\delta^2\) per group, about \(16\sigma^2/\delta^2\) for α = 0.05 and 80% power. Smaller effects need quadratically more users ([[causal]]).
Dropout at inference?
Disabled. With inverted dropout, activations are scaled by \(1/(1-p)\) during training so expectations already match. (Keeping it on deliberately gives MC-dropout uncertainty estimates.)
Why are output tokens slower and pricier than input tokens?
Input (prefill) is processed in parallel and is compute-bound. Output is generated one token at a time; each step reads all weights and the KV cache from memory, so it's memory-bandwidth-bound with low utilization.
