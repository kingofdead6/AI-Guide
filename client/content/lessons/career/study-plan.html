The plan

About 15 hours a week. Each phase ends with a checkpoint project you can show; the guided projects page has detailed milestones for several of them.

Faster is fine: if a course covers things you know, read the lessons quickly and pass the quizzes. Slower is fine too; consistency beats intensity. The day-streak counter on My progress exists for exactly this reason.

How to make it stick

Re-derive one key result from memory every week (normal equations, softmax gradient, backprop, attention, ELBO, policy gradient, DPO). Write a short README or blog post for every project. Explaining is the fastest way to find what you don't yet understand.
